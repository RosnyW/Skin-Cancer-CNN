# Same_DA_With_Swish
This project implements a CNN-based model for **skin cancer detection** using the **HAM10000 dataset**.  
The model uses Swish activation and advanced data augmentation strategies to improve generalization.

## 🔍 Overview
- Framework: TensorFlow / Keras  
- Dataset: HAM10000  
- Architecture: 5 Convolutional Blocks with Swish Activation  
- Accuracy: Achieved ~93% test accuracy

## ⚙️ How to Run
1. Clone the repository  
2. Open `Same_DA_With_Swish.ipynb`  
3. Run all cells in Jupyter Notebook  

## 📈 Results
The model achieves balanced performance across all 7 skin lesion classes.
